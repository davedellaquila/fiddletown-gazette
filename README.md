# The Fiddletown Gazette

A public hyperlocal daily newspaper for Fiddletown & the Shenandoah Valley — safety news neighbors need (burn bans, fire and emergency alerts, road closures, outages) leading every edition, plus the valley's complete public events listing, winery events first.

- **Editions:** Morning ~7:00 AM · Midday ~12:30 PM · Evening ~5:30 PM PT, plus hourly safety polls with out-of-cycle banners.
- **Site:** https://davedellaquila.github.io/fiddletown-gazette/ (GitHub Pages, this repo — goes live when this repo is created and pushed)
- **Editor:** Gazette Buddy ("The Editor"), child of Neighborhood Buddy. Publisher: Dave Dell'Aquila (colophon only).
- **Privacy line (non-negotiable):** public sources and public events only. See `PUBLISHING.md` for the cadence, sources, and the pre-publish gate.

Status: LIVE — repo created and first edition (Morning, Sat Oct 31, 2026) published Oct 31, 2026 at Dave's go-ahead. Midday + Evening editions follow today's rhythm.
